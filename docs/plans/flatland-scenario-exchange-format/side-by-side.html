Boxes with the same number hold the same value on both sides (1:1, possibly reshaped: moved, grouped, or renamed as a key). Grey comments mark what is derived, converted or not in the format.

      1,  // middle row

   }

   {
    "handle": 0,

     [{
      "position": [120, 1317],
      "direction": 1  // derived from the rail
     }],
     [{"position": [172, 1828], "direction": …}],
     …,
     [{"position": [148, 1571], "direction": null}]
    ],

  • Scene x, y become [row, column] = [y, x]: the same numbers, swapped.
  • Not 1:1: the rail (cells and graph are converted to transitions), display names (looked up), placement, the order along the line, tracks per station and the single-track section (derived).
